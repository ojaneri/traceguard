🔍 Sistema de Coleta de Evidências Digitais

Informe a URL a ser coletada. O sistema fará screenshot, coletará headers HTTP, WHOIS/DNS/TLS, calculará SHA-256 e gerará um relatório jurídico profissional em PDF.

Processando coleta de evidências...

📋 O que é coletado:

  • Screenshot: Captura visual da página web
  • Headers HTTP: Informações técnicas da comunicação
  • WHOIS: Dados de registro do domínio
  • DNS: Registros de resolução de nomes
  • TLS/SSL: Certificados de segurança
  • Hashes SHA-256: Verificação de integridade
  • Relatório PDF: Documento jurídico profissional
