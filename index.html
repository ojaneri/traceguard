TraceGuard

Sistema avançado para coleta de evidências web com preservação de cadeia de custódia. Capture screenshots, metadados e gere relatórios completos de qualquer URL.

🚀 Acessar Aplicação 📖 Documentação

Funcionalidades:

  • Screenshots em alta resolução (1366x768)
  • Coleta de headers HTTP completos
  • Análise de DNS e WHOIS
  • Informações de certificado TLS/SSL
  • Cálculo de hashes SHA-256
  • Manifest.json com cadeia de custódia
  • Exportação em formato ZIP
